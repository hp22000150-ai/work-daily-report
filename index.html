날씨·기온 📍자동
GPS 기반 최저·최고 기온·날씨 자동 입력. 위치 권한 및 인터넷 연결 필요.

👷 인력 투입
직종·성명 드롭다운 선택. 공수 직접 입력 (0.5/1.0 또는 숫자). 헤더 배지 실시간 표시.
⏮ 전날 복사: 전날 인력·장비 한번에 복사.
누계 — 같은 공사명·같은 달 기준, 당일 이전 합산 자동 계산. 월이 바뀌면 초기화.

🚜 장비 투입
장비명·기사명·시간 입력. 금액(원) 직접 입력 시 정산 시 단가 계산 대신 해당 금액 사용. 금액은 천단위 콤마 표시.

📦 자재 반입
품명·규격·단위·수량·거래처 입력.

📷 현장 사진
최대 6장 추가. 자동 압축(JPEG) 저장. 일지 미리보기 하단에 현장 사진표로 출력.
모바일에서 사진 포함해 가져온 데이터도 그대로 표시됩니다.
