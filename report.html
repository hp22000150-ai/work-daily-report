📥 데이터 불러오기
모바일에서 내보낸 JSON 파일을 선택하면 정산 데이터로 불러옵니다.
기존 데이터가 있으면 초기화 후 새로 불러오기 또는 기존에 추가를 선택할 수 있습니다.
여러 파일을 한번에 선택해도 됩니다.

📂 data 폴더 불러오기
Electron 앱 환경에서 사용 가능. data 폴더 안의 JSON 파일 전체를 한번에 불러옵니다.

기간 / 공사명 필터
시작일·종료일·공사명을 설정하면 해당 조건의 데이터만 집계합니다.
공사명을 선택하지 않으면 전체 현장을 합산합니다.

👷 인력 정산
기간 내 일보에서 성명·직종별 공수를 자동 합산합니다.
단가 입력 → 합계 = 공수 × 단가 자동 계산.

🚜 장비 정산
장비명별 투입 시간·일수를 자동 합산합니다.
단가 입력 → 합계 자동 계산. 부가세 10% 체크박스로 VAT 포함 총액 계산 가능.
일보에 금액이 직접 입력된 경우 해당 금액을 그대로 사용합니다.

💾 단가 저장
입력한 단가를 저장하면 다음 방문 시 자동으로 불러와집니다.
저장 버튼을 누르지 않으면 단가가 유지되지 않습니다.

📦 통합 파일로 저장
불러온 데이터를 하나의 JSON 파일로 합쳐서 저장합니다. 데이터 백업·이관에 활용하세요.
